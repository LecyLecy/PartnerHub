# Shared API contracts

Only agreed transport types belong here. No runtime services, Prisma models, secrets, or frontend components. This shared folder requires explicit approval before edits.

Current files: `account.ts`, `event.ts`, `participation.ts`, `committee.ts` (recruitment and applications), and `sponsor-offer.ts` (organizer-initiated sponsor requests). They describe the API the frontend expects; the backend is **In progress**.
