# Self-hosted typography

Bricolage Grotesque (700) carries the expressive campus-program headings. Manrope (400, 600) keeps forms and operational text readable at larger sizes. Fonts are served locally, not requested from Google by visitors.

Downloaded from Google Fonts on 2026-10-05. The adjacent OFL license files come from the Google Fonts repositories `ofl/bricolagegrotesque` and `ofl/manrope`. No generated brand or person imagery is used.
